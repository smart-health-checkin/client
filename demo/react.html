Same core, React bindings

@smart-health-checkin/client/react wraps the <smart-checkin-picker> element as a component. It's the same UI every page gets, with callbacks for the result. Pages that draw their own buttons can use the useCheckin hook from the same module instead.

The component

import { CheckinPicker } from "@smart-health-checkin/client/react";

<CheckinPicker
  request={REQUEST}
  wallets="/wallets.json"
  onResponse={({ response }) => setResponse(response)}
  onDeclined={() => setNote("Nothing was shared.")}
/>

Or draw your own buttons

import { useCheckin } from "@smart-health-checkin/client/react";

const { responders, start, status, response } = useCheckin(REQUEST, { webWallets: "/wallets.json" });

// start(r) opens a web wallet's tab inside the click, so call it from onClick
{responders.filter((r) => r.available).map((r) => (
  <button key={r.id} onClick={() => start(r)}>{r.name}</button>
))}
